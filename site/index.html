A quiet board for your notes and pull requests.

Stow keeps your Markdown notes and the GitHub pull requests that need you in one small native window. Free, open source, and local to your Mac.

Small, native, and out of your way

Every choice in Stow is a default you can change, and nothing turns on until you say so.

  • Notes are plain Markdown

    Every note is a .md file you can open in any editor. Stow reloads outside changes and keeps both versions if they ever clash.

    # Flaky upload test
Repro on a slow network:

```sh
npm test -- --grep upload
```

  • Pull requests that need you

    Needs you and Waiting, from the GitHub CLI login you already have. Partial data never looks ready to merge.

  • A profile for each part of your day

    Keep work and personal apart, each with its own notes, cards, theme, and windows. Switch with ⌃⌥1 through ⌃⌥9.

  • Your layout, your defaults

    Section order, cards per section, collapsed notes, even the header title. Every choice is a setting.

  • Themes are a few lines of text

    Copy a theme as key = value, share it in a message, and paste it on another Mac.

  • Private by design

    No account, analytics, or server. Your notes stay on your Mac, and Stow never reads your GitHub token.

Share a theme like a terminal config

Start from a preset, change what you like, and copy it as text. Import and export use plain .conf files.

preset = graphite
font-family = Menlo
font-size = 14
background-opacity = 0.85

Get Stow

Build from source

Needs Xcode 16.4 or later, which runs on macOS 15.3 or later. Unzip build/Stow.zip and move Stow.app to Applications. The package is for your own Mac.

git clone \
https://github.com/byanthny/stow.gitcd stow./scripts/package.sh

Connect GitHub, if you want

Install the GitHub CLI and sign in once. Stow asks before using it, and notes work without it.

gh auth login --hostname github.com
